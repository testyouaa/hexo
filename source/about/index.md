# 关于我
**网名：西楼 男，80后，小时候梦想像金庸武侠里面的大侠仗剑走天涯，后来接触计算机和网络梦想像黑客高手一样纵横虚拟世界** 
实际是打了多年的工，和喜欢的半点不相关。 

**从小喜欢捣鼓各类电子产品和软件相关的新鲜东西，一般兴趣持续不太久，就导致没有什么精通的领域。**  

工作20年后，跟随内心的fire火种依然提前退休了，过起了每天喝茶、看书、接送孩子、做饭、运动的生活。

这个个人小站也是多年的一些爱好之一，做了好多个都没维持下去。今天重整旗鼓用github和cloudflare worker搭建了这个静态网站，没有任何费用，这样至少我没兴趣了它依然还在。但还是希望能长期维持下去，不要一阵热情过了就不更新过了。
