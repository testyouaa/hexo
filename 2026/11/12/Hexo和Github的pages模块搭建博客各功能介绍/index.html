hexo和github的pages模块搭建博客各功能介绍

用 Hexo + GitHub Pages 搭建博客：我的双仓库方案

这两天我从头学习用 Hexo 和 GitHub Pages 搭建博客，基本弄明白了原理，想把自己的经验分享出来。

博客的基本结构
我用了两个 GitHub 仓库来存储内容：

源码仓库（私有）：存放 Hexo 源代码，别人看不到。

静态文件仓库（公开）：存放生成的静态 HTML 文件。只有公开仓库才能启用 Pages 页面，这样既能把源码隐藏起来，又能正常对外访问。

日常我使用 VSCode 编写博客内容。写完后，通过 VSCode 的 Git 功能同步到私有仓库，再用 Hexo 命令把静态页面部署到公开的 HTML 仓库。

整体架构
这套架构既安全又规范：

本地电脑：用 VSCode 编写源码。

私有仓库（仓库名可自定，比如 hexo_s）：只存源码（.md 文件），别人看不见，安全第一。

公开仓库（仓库名可自定）：只存 gh-pages 分支的网页文件，供人访问。

独立域名（blog.505899.xyz）：通过 Cloudflare 解析，已开启 HTTPS 安全锁。

日常发布流程
保存源码
写完文章后，在 VSCode 左侧打开“源代码管理”，依次点击 提交 和 同步更改。

发布网页（上线）
在终端执行：

bash
hexo clean && hexo g -d
看到 INFO Deploy done: git 后，等几分钟，刷新网页即可。
